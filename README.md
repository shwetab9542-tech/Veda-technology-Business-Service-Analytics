# Veda Technology Business & Service Analytics

## Project Overview

This project analyzes synthetic business data representing website visitors, internship applications, training programs, IT services, digital services, customer inquiries, marketing channels, and business performance.

## Objectives

* Clean and preprocess business data.
* Analyze website and marketing performance.
* Study internship and training program activity.
* Analyze IT and digital service inquiries.
* Segment customers by type and engagement.
* Calculate business KPIs.
* Demonstrate predictive classification.
* Design a Power BI business dashboard.

## Tools and Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Jupyter Notebook 
* Microsoft Excel
* Microsoft Power BI
* Git and GitHub

## Dataset

The project uses 1,000 synthetic records with 16 columns. The dataset is created for educational purposes and does not contain confidential company data.

## Project Workflow

1. Dataset creation and loading
2. Data cleaning and preprocessing
3. Website visitor analysis
4. Internship application analysis
5. Training program analysis
6. IT and digital service analysis
7. Customer and service request analysis
8. Marketing channel analysis
9. Customer segmentation
10. Service demand analysis
11. KPI calculation
12. Predictive classification
13. Monthly trend analysis
14. Power BI dashboard
15. Business recommendations

## Key Outputs

* Synthetic CSV and Excel datasets
* Cleaned dataset
* Business analysis tables
* Machine learning evaluation
* Power BI dashboard
* Executive-level report

## Conclusion

This project demonstrates the use of data analytics and machine learning for business intelligence and data-driven decisions. All findings are based on simulated data.


## Disclaimer

This is an educational project. The synthetic data and model results should not be interpreted as actual Veda Technology business performance.
